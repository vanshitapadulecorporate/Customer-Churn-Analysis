# Customer-Churn-Analysis

A data analytics project focused on understanding **customer churn behavior** and identifying the key factors that influence customers to leave a service.

# Tools Used

* SQL (MySQL)
* Python (Pandas, Matplotlib, Seaborn)
* Excel

# Project Highlights

* Cleaned and analyzed customer churn data
* Performed SQL-based customer analysis
* Analyzed churn based on contract, tenure, internet service, payment method, and other factors
* Created visualizations to identify churn patterns

*Skills:* SQL | Python | Data Analysis | Data Visualization | Customer Analytics
